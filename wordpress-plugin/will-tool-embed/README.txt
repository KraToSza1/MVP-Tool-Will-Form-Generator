=== Will Tool Embed ===

Install: Zip the folder "will-tool-embed" (so the zip contains will-tool-embed.php at root of the folder), then WordPress → Plugins → Add New → Upload Plugin.

After activation: Settings → Will Tool Embed. Enter your Will Tool app URL and save.

Use shortcode [will_tool] in any page or post. In Elementor: add the "Shortcode" widget and type [will_tool].
